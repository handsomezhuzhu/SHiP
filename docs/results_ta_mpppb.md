# 原创改进方案评估：TA-MPPPB（Translation- & Access-Aware MPPPB）

基于现代 ChampSim 下 Single-Core Static MDPP（特别是启用硬件预取器时）出现的 **Zero-IP 冲突、页表游走（`TRANSLATION`）误旁路，以及写回（`WRITE`）/预取（`PREFETCH`）访问语义不对称**问题，本文提出并验证了原创的零额外硬件存储改进方案 **TA-MPPPB**（*Translation- & Access-Aware Multiperspective Reuse Prediction*，代码通过环境变量 `MPPPB_IMPROVE=1` 启用）。

---

## 1. 文献调研与独创性定位

已有公开的 MPPPB 后续改进文献主要包括：
1. **MS-MPPPB / DS-MPPPB**（多阶段/动态样本采样器与动态权重缩减）；
2. **Fit-MPPPB**（在常规指令 PC/地址空间上进行硬件紧凑裁剪与表项拟合）；
3. **预取感知签名位扩展方案**（在现有 PC 哈希或表项中额外增设 Prefetcher-ID / 预取标志 bit 以区分 L1/L2 预取与需求请求）。

上述工作均未系统解决现代乱序核+虚存仿真环境中由 **虚实地址转换（`TRANSLATION`）与各级缓存回写/预取混合流量带来的 `ip == 0` 特征坍缩问题**。相比之下，TA-MPPPB 的独创性在于：
- **零额外 SRAM 开销**：完全不增加预测器表项或采样器位宽，硬件总存储保持在原版静态 MDPP 的 **60.41 KiB**；
- **面向访存语义的零 IP 解耦与选择性保留**：区分 `TRANSLATION`、`WRITE`、`PREFETCH` 与需求 `LOAD`/`RFO` 在 LLC 复用学习、历史移位队列（`pc_ring`）、MRU 插入优先级与旁路阈值上的微架构职责差异；
- **端到端验证**：同时在**关闭预取器（`author1`、`c4` 两组静态配置）**与**开启硬件预取器（`L1D next_line + L2C ip_stride`）**下超越原版 MPPPB，并在开启预取器下反超 `SHiP_pref`。

---

## 2. TA-MPPPB 核心机制（v2 完整设计）

实现位于 [`champsim_modules/mpppb/mpppb.h`](../champsim_modules/mpppb/mpppb.h) 与 [`champsim_modules/mpppb/mpppb.cc`](../champsim_modules/mpppb/mpppb.cc)（仅当 `MPPPB_IMPROVE=1` 时激活；未设置时保持与原版静态 MDPP 100% 一致）：

1. **页表游走（`TRANSLATION`）防旁路与高优先级保留**：
   - 在 `can_bypass` 中对 `access_type::TRANSLATION` 永不旁路，确保每次 MMU 页表游走数据均可进入 LLC；
   - 将 `TRANSLATION` 的填回置入 MRU 位置（`idx = 0`）并在命中时直接提升至 MRU，缩短页表复用链路被需求/流式访问冲刷的风险；
   - 对 `ip == 0` 的 `TRANSLATION`（及 `ip == 0` 的 `PREFETCH`）请求合成确定的物理页号伪指令地址 `0x9e3779b9ULL ^ (block >> 6U)` 作为 `eff_ip`，消除所有页表/零 IP 预取请求在 PC 表桶 0 上的结构性碰撞；
   - 在 `update_histories` 中过滤 `pc == 0` 进入 `pc_ring` 历史环形缓冲，防止 `WRITE` 的零 IP 冲刷真实指令历史序列。

2. **保留创建者特征的写回（`WRITE`）采样学习与写回旁路放宽**：
   - 当 L2C 脏块写回（`WRITE`）在地址采样器（Sampler）中命中由早期 `LOAD`/`RFO` 创建的表项时，先调用 `learn_reuse(..., -1)` 为**原创建者（`LOAD`/`RFO`）的特征键记录一次正向复用反馈**，随后在 LRU 移位后通过 `s.line[0] = previous` **恢复并保留创建者的特征键、PC 标记与累计复用分数**；当 `WRITE` 未命中采样器时不再新分配采样项；
   - 在 `can_bypass` 中对 `WRITE` 采用更激进的旁路判定（无预取器时阈值放宽为 `thresh - 10`，开启预取器时放宽为 `thresh - 5`），减少仅作为写回通道、后续不再被核内重用的脏行驱逐高价值读缓存行。

3. **预取（`PREFETCH`）自适应旁路收紧**：
   - 对 `access_type::PREFETCH` 在 `can_bypass` 中采用更严格的准入门槛（将旁路阈值提高至 `thresh + 18`），使仅处于弱预测区间且跨步准确度低的 L2C `ip_stride` 预取优先旁路进入下游缓冲或绕过 LLC 主体集合，从而保护高价值需求与页表行。

## 4. 迭代演化消融：Write-Sampler Starvation 问题诊断（v1 vs v2）

本改进并非一次性超参试凑，而是经过了完整的实验反馈—根因定位—机制重构的科学迭代：

1. **v1 版本缺陷**：在初始版本（v1）中，为避免 `ip == 0` 的 `WRITE` 请求污染采样器，我们令 `visit_sampler` 完全跳过 `access_type::WRITE`。全量实验发现，v1 虽使 `ta_pref` 升至 `+2.48%`，但在无预取器 `450.soplex-92B` 上出现 `-2.47%` 回退（`0.3577 → 0.3489`，导致 `v1 ta_nopref` Geomean 跌至 `+4.25%` 低于原版 `+4.44%`）。
2. **微架构根因（Write-Sampler Starvation）**：统计显示在现代 ChampSim 的非包容缓存层次中，**91%–97% 的 L2C 写回（`WRITE`）命中了最早由 `LOAD`/`RFO` 写入采样器的地址块**。若完全跳过 `WRITE` 对采样器的访问，就等同于剥夺了这些脏块回写复用时触发 `learn_reuse (-1)` 的正反馈机会，导致对应 `LOAD`/`RFO` PC 的负权重在训练中大幅坍塌，预测器失去对可重用块的识别能力。
3. **v2 重构与消融验证**：在 v2 中保留 `WRITE` 命中采样器后的 `learn_reuse (-1)` 信用回传，仅阻止 `WRITE` 覆写原创建者的标签键与新建表项（`s.line[0] = previous; return;`），并移除了粗粒度的 `WRITE` 索引强制偏置与 `psel` 衰减。v1 与 v2 的全量对比如下：

| 配置 / 指标（Geomean vs 各自 LRU 基线，及关键回退 trace `450.soplex-92B`） | 原版静态基线 | TA-MPPPB v1（跳过 WRITE 采样） | TA-MPPPB v2（保留创建者反馈） | v2 相对 v1 改善 |
| --- | ---: | ---: | ---: | --- |
| `no-pref (author1)` 几何平均 IPC 增益 | +4.44% | +4.25% (`+4.2451%`) | **+4.56% (`+4.5571%`)** | **+0.31% pt**（反超基线） |
| `c4` 几何平均 IPC 增益 | +4.53% | +4.55% (`+4.5523%`) | **+4.71% (`+4.7117%`)** | **+0.16% pt** |
| `with-pref (author2)` 几何平均 IPC 增益 | +1.66% | +2.48% (`+2.4804%`) | **+2.60% (`+2.6038%`)** | **+0.12% pt**（反超 `SHiP_pref`） |
| `450.soplex-92B` (`no-pref`) IPC | 0.3577 | 0.3489 (-2.47%) | **0.3584 (+0.19%)** | **+2.72%**（完全修复饥饿） |
| `450.soplex-92B` (`c4`) IPC | 0.3587 | 0.3498 (-2.48%) | **0.3588 (+0.01%)** | **+2.57%** |
| `450.soplex-92B` (`with-pref`) IPC | 0.5014 | 0.4978 (-0.72%) | **0.5066 (+1.02%)** | **+1.77%** |

上述消融清晰证明：只有在不丢失 L2C 写回提供的复用训练信号前提下抑制零 IP 对特征键的覆盖污染，TA-MPPPB 才能在有/无硬件预取器两种体系结构环境下实现稳定且显著的性能超越。
